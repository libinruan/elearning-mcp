# MCP Mastery — study & interview prep

A local website that digests the official Model Context Protocol documentation
([modelcontextprotocol.io](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro), spec revision
**2026-07-28**) into a 28-lesson course for AI engineers who build agentic applications and workflows.
Every lesson has:

- a **digest** of the official docs and spec pages (with links to each source), a summary and key points
- a **Jupyter notebook** that runs real MCP servers and clients with the official Python SDK (`mcp` 2.3.0) — offline,
  in-process, over stdio and over Streamable HTTP on localhost
- **30-second pitches** (elevator answers) for the key ideas, with a rehearsal timer
- **interview questions** with model answers you can mark *Got it* / *Review again*
- a bilingual **glossary** (English · 中文), merged course-wide on the Glossary page

The whole site is available in **English and Simplified Chinese** — use the **EN / 中文** toggle in the header (your
choice is remembered). The Chinese version keeps the English term in parentheses after key terminology, e.g.
宿主（Host）, and each lesson has a Chinese twin of its notebook with identical code.

A **Study plan** page lays out a 4-week agenda: concepts → wire protocol → server side → client side → security →
ecosystem → capstone.

## Run it

```bash
python run.py
```

This opens <http://localhost:8000> and starts JupyterLab in the background, so the
"Open the notebook in JupyterLab" button on each lesson works. `Ctrl+C` stops both.

Options: `--port 8001`, `--no-browser`, `--no-jupyter`.

First-time setup on another machine:

```bash
uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.txt
```

Notebooks never need an API key. Cells that let a real model (Claude) drive the tools are skipped unless
`ANTHROPIC_API_KEY` is set in the environment you start `run.py` from; each has an offline scripted fallback.

## Layout

| Path | What it is |
| --- | --- |
| `content/course.json` | Modules, lessons (sources, study time) and the 4-week plan — generated by `content/make_course.py` |
| `content/lessons/X-Y.md` | One file per lesson: summary, lesson digest, key points, pitches, Q&A, glossary, notebook cells |
| `content/lessons/zh/X-Y.md` | The Chinese translation of each lesson, same format (see `content/AUTHORING.md`) |
| `content/AUTHORING.md` | The lesson format and verified notes on the `mcp` 2.x SDK |
| `build.py` | Turns `content/` into `site/data/course.json` and `notebooks/*.ipynb` |
| `notebooks/` | The practice notebooks. Your edits are kept; they are only regenerated with `--force` |
| `notebooks/zh/` | The Chinese notebooks (translated markdown, the same code), opened when the site is in 中文 mode |
| `site/` | The website (plain HTML/CSS/JS, no build step) |
| `run.py` | Rebuilds the site data, then serves the site and JupyterLab |

## Editing or adding content

Edit a `content/lessons/X-Y.md` file (see `content/AUTHORING.md`) and restart `run.py`.
In the `## Notebook` section, ```` ```python ```` blocks become runnable cells; everything else is markdown.

```bash
.venv/bin/python build.py --check 5-3    # parse one lesson and execute its notebook
.venv/bin/python build.py --check all    # the same for every lesson
.venv/bin/python build.py --force        # reset all notebooks to the originals (discards your edits)
```

## Notes

- Progress (done lessons, Q&A marks) is saved in your browser's local storage for `localhost:8000`.
- MCP moves fast. This course targets spec **2026-07-28** (stateless requests, `server/discover`, multi round-trip
  requests, `subscriptions/listen`) and notes where it differs from 2025-11-25, which you will still meet in real code.
- The digests, notebooks and interview material are study aids written from the public documentation; they are not
  official MCP material. The specification is the source of truth.
