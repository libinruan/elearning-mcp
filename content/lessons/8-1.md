## Summary
This capstone pulls the whole course into one realistic agentic workflow: a research assistant that searches a document library, reads sources, drafts a cited report in a notes service, revises it, and publishes it — but only after a human says yes. Three MCP servers run on three transports (in-process, a **stdio** subprocess, **Streamable HTTP** with a bearer token), and a host connects them, namespaces and caches their tools, enforces an allowlist and a step budget, traces and audits every call, and drives a Claude-shaped tool-use loop. You will justify each design decision against the 2026-07-28 spec, run the workflow offline with a deterministic planner, inject failures, and pin the behaviour with end-to-end tests.

## Lesson
### The brief
A product team asks for an assistant that answers: *"Research how MCP servers scale horizontally, write a short cited report in my notes, and publish it to the team wiki."* It is a good capstone because it exercises every layer you have studied: **resources** and **tools** (module 3), server design (module 4), the host and its loop, **MRTR** and **elicitation** (module 5), authorization and prompt-injection defence (module 6). It is also a shape you will meet in interviews: *"design an agent that reads from system A, writes to system B, and must never do something irreversible on its own."*

Requirements, written the way you would in a design doc:

- **Functional:** keyword search over a corpus; read full documents; create and edit a draft across many calls; publish a final report.
- **Safety:** publishing is irreversible → explicit human confirmation; the model may only use the tools this workflow needs; content read from documents is untrusted.
- **Operational:** every call auditable and traceable; bounded cost (step cap, truncated outputs); the drafting state must survive a process restart; everything testable without an LLM.

The happy path is eight model turns: `search_docs` → `search_docs(cursor)` → two parallel `host__read_resource` → `create_draft` → two parallel `add_section` → `revise_section` → `get_draft` → `publish` (one confirmation dialog) → final answer.

### How each part maps to a protocol feature

| Part | Protocol feature | Rule that drives the design |
| --- | --- | --- |
| Library documents | **Resources** + template `library://docs/{doc_id}` | Resources are application-controlled context; `resources/read` carries `ttlMs` and `cacheScope` |
| Library search | **Tool** with `outputSchema`, cursor pagination | Results are `structuredContent` for programs and text for the model; pages stay small |
| Notes drafts | **Stateful tool** pattern (explicit handle) | Stateless protocol: state spanning requests **MUST** be referenced by an explicit identifier |
| Notes transport | **stdio** | Credentials come from the environment; the process is *not* a session |
| Publisher transport | **Streamable HTTP** + OAuth resource server | `401` + `WWW-Authenticate`; tokens must be issued for this server |
| Confirmation | **MRTR** (`InputRequiredResult`) carrying `elicitation/create` | Servers MUST NOT send server-initiated requests in 2026-07-28 |
| Tracing | `_meta.traceparent` (W3C Trace Context) | Reserved `_meta` key for OpenTelemetry propagation |
| Tool catalog | `tools/list` + caching hints | Follow `ttlMs`; treat `list_changed` as invalidation |

### Decision 1 — one transport per trust boundary
Transports are not interchangeable decoration; they encode **where the code runs and who it trusts**. The library runs in-process because it is our own code and we want fast deterministic tests (`Client(server)`). The notes service is a local program, so it runs as a **stdio** subprocess: the host owns its lifecycle and passes identity through the environment (the spec says stdio implementations SHOULD NOT use the HTTP authorization framework and should "retrieve credentials from the environment"). The publisher is a shared remote service, so it speaks **Streamable HTTP**, validates a bearer token, and would validate `Origin` and bind to localhost when run locally. The build-server guide's logging rule applies to the stdio server: **never write to stdout** — it is the JSON-RPC channel; log to stderr.

### Decision 2 — data as resources, search as a paginated tool
Dumping documents into tool results wastes the context window and blurs control. The library exposes documents as **resources** and a `search_docs` tool that returns at most three hits with 160-character snippets and an opaque `next_cursor`. The model decides *what* to read; the host performs the read through a single host-level tool, `host__read_resource`, which only accepts URIs of connected servers and truncates long payloads. This is how resources — application-controlled by design — enter an agent loop without giving the model a generic fetch-anything capability.

### Decision 3 — state through handles, not sessions
2026-07-28 removed protocol sessions (`Mcp-Session-Id`, the `initialize` handshake). The spec is explicit that "an open connection, such as a STDIO process, is not a conversation or session", and that clients SHOULD NOT tie the stdio process lifetime to one conversation. So `create_draft` mints an opaque, high-entropy `draft_id`, every other tool takes it as an argument, the description states the lifetime ("expire after 24 hours without changes"), and an unknown handle returns a **tool execution error** telling the model to create a new draft. Storage is keyed `<user>:<handle>` with the user taken from the verified environment, implementing the security guidance that servers **MUST NOT** treat possession of a handle as authentication and SHOULD bind handles to the principal. The notebook proves the payoff: kill the subprocess, start a new one, and the handle still works.

### Decision 4 — confirmation through MRTR
In 2025-11-25 a tool could pause mid-call and send `elicitation/create` to the client on the SSE stream. In 2026-07-28 that is gone: `publish` **returns** `{"resultType": "input_required", "inputRequests": {"confirm": {...elicitation/create...}}, "requestState": "..."}` and terminates. The client shows the dialog, then retries `tools/call` with a **new JSON-RPC id**, `inputResponses`, and the exact `requestState`. Consequences you should be able to recite:

- The server holds no state between rounds, so **any replica** can finish the retry — provided all replicas can verify `requestState` (shared key; lesson 8.2).
- `requestState` is attacker-controlled input. The SDK seals it (AES-GCM, TTL, principal binding); our tool additionally binds approval to a digest of the content, so a retry with an edited report cannot reuse the "yes".
- Servers **MUST NOT** send input requests the client hasn't declared — our tool answers `-32021` (`MissingRequiredClientCapability`, HTTP 400) when `elicitation` is missing.
- Form mode **MUST NOT** request secrets; a yes/no approval is fine. Decline and cancel must be handled — our tool turns them into a clear `isError` result that tells the model not to retry.

### Decision 5 — the host is the policy engine
Servers are plug-ins of varying trust; tool descriptions and annotations are untrusted unless the server is trusted. Every guarantee therefore lives in the host:

- **Namespacing.** Tool names are unique only per server, and the spec says aggregators SHOULD disambiguate (and SHOULD NOT rely on `serverInfo.name`). We expose `library__search_docs` etc., using characters that are valid both for MCP and for model-provider tool names.
- **Least privilege.** An allowlist filters the catalog *and* is re-checked at call time, because a model can name a tool it was never shown (hallucination or injection). `publisher__unpublish` exists on the server but is unreachable from this workflow.
- **Caching.** The merged catalog is memoised until the smallest `ttlMs` expires — the client best-practices guide recommends caching definitions host-side and refreshing on `list_changed`. A stable `tools` array also preserves the model provider's prompt cache.
- **Audit and tracing.** One record per call (tool, arguments, outcome, latency) and a fresh `traceparent` span under one trace id in each request's `_meta` — the tools spec says clients SHOULD log tool usage for audit, and the reserved `traceparent`/`tracestate`/`baggage` keys let backends join the trace.
- **Context hygiene.** Tool output is truncated before it reaches the model; protocol errors and transport failures are converted into `is_error` tool results so the loop never crashes.

### The loop and its guard rails
The build-client tutorial makes one round of tool calls; a workflow needs a **loop**: call the model; while `stop_reason == "tool_use"`, execute every `tool_use` block, append the assistant turn, then one user turn containing all `tool_result` blocks with `is_error`, and call again. Two rules from the tutorial matter: a failing MCP tool does **not** raise in the client — check `result.is_error` and pass the flag on so the model can self-correct; and the loop needs a budget (`max_steps`) because a model that never converges costs money. Parallel tool calls (two reads, two `add_section`s) come for free with this shape.

### Testing an agent workflow
LLM output is non-deterministic, so test the **system** with a deterministic planner that has the exact `messages.create` signature and emits Anthropic-shaped `tool_use` blocks. It reads tool results like a model would (cursors, URIs, `draft_id`), so it exercises the real servers, transports, policies and loop. Then assert on observable behaviour: the order of calls in the audit log, exactly one confirmation dialog, the trace id seen by the HTTP server, the published body, and that failures (a flaky tool, an injected instruction, a "no") become recoverable errors. Swap in Claude only for an optional live run.

### Trade-offs and what changes at scale
- **Many servers:** at dozens of servers, switch to progressive discovery (`search_tools`, connect servers on demand); the guide suggests switching when definitions exceed roughly 1–5% of the context window.
- **Big intermediate data:** chaining read → transform → write through the model is expensive; programmatic tool calling ("code mode") runs a model-written script in a sandbox, with the same per-call authorization in the broker.
- **Confirmation UX:** per-call approval is safest but tiring; categorical grants ("allow `publish` for this run") are acceptable only if the host still evaluates each call.
- **Long jobs:** publishing that takes minutes would use the Tasks extension instead of holding a request open (lesson 7.1).
- **Real auth:** replace the demo token dict with an OAuth 2.1 authorization server, audience-bound tokens and scope step-up (module 6) — never pass the user's token through to downstream APIs.

## Key points
- A capstone-grade MCP system separates **servers** (capabilities) from the **host** (policy): namespacing, allowlist, caching, truncation, audit and tracing all live in the host.
- Choose the transport per trust boundary: in-process for tests, **stdio** for local programs (credentials from env, never print to stdout), **Streamable HTTP** + OAuth resource server for shared services.
- Expose bulk data as **resources** and give the model a small, paginated search **tool**; bridge reads through a host tool that validates URIs and truncates.
- Cross-call state uses **explicit, high-entropy handles** bound to the user; an open stdio process is not a session, and a restart must not lose the work.
- Irreversible actions confirm through **MRTR**: `resultType: "input_required"` + `elicitation/create`, retried with a new id, `inputResponses` and the echoed, integrity-protected `requestState`.
- Re-check the allowlist at call time: models can call tools they were never shown, and **prompt injection** is defeated by host code, not by model behaviour.
- The loop runs while `stop_reason == "tool_use"`, returns all `tool_result`s in one user turn with `is_error`, and is capped by `max_steps`.
- Put a W3C `traceparent` in every request's `_meta` and keep one audit record per call — this is the observability backbone of lesson 8.2.
- Test agents with a deterministic planner that has the model API's exact shape, then assert on the audit log, side effects and failure recovery.

## Pitches
### Walk me through an agentic workflow you built on MCP.
I built a research assistant that searches a document library, drafts a cited report and publishes it. It uses three MCP servers on three transports: an in-process library exposing documents as resources with a paginated search tool, a notes server over stdio that keeps drafts behind explicit handles, and an HTTP publisher protected by a bearer token whose publish tool asks the human through an MRTR elicitation. The host namespaces and caches tools, enforces an allowlist, traces and audits every call, and runs a bounded tool-use loop.

### How do you keep a human in the loop for irreversible actions?
I make the server ask, not the model. In MCP 2026-07-28 the publish tool returns an input-required result containing an elicitation request and an opaque, sealed request state; the client shows a confirmation dialog and retries the call with the user's answer. I bind the approval to a digest of the content so it can't be reused for something else, handle decline and cancel as clean tool errors, and on top of that the host only allowlists the tools this workflow actually needs.

### How do you keep state in a stateless protocol?
I make state explicit. A creation tool mints an opaque, high-entropy handle, every later call passes it as an argument, and the server stores the state in a database keyed by user and handle. The tool description states how long handles live, and an unknown handle returns a tool error telling the model to start over. Because nothing depends on the connection, any replica can serve any call, a stdio process can restart, and possession of a handle alone never grants access.

## Interview
### Why enforce the tool allowlist in the host when you already filter the tool list the model sees?
Because the catalog only controls what the model is *told*, not what it *asks for*. A model can hallucinate a tool name, and a prompt injection inside a document can instruct it to call a destructive tool by name — in the capstone, a "SYSTEM NOTE" in a document tells the agent to call `publisher__unpublish`. If the host simply routed every `tool_use` to the server that owns the prefix, that call would succeed. Re-checking the allowlist at call time turns the policy into code that holds regardless of model behaviour, and the denial is logged in the audit trail as its own outcome.

### How do you test an LLM agent workflow deterministically?
Separate the **planner** from the **system**. Write a fake LLM with the exact signature of `messages.create` that returns Anthropic-shaped `tool_use` blocks and reads the `tool_result`s in `messages` to choose its next step. Run it against the *real* servers, transports, host policies and loop. Then assert on observable effects: call order in the audit log, side effects (the published report), number of confirmation dialogs, trace ids received by the HTTP server, and recovery from injected failures (a flaky tool, a denied call, a declined confirmation, a runaway loop hitting `max_steps`). Keep a separate, optional evaluation suite with the real model for quality.

### A tool fails mid-workflow. What should the host send back to the model, and when should it stop?
Distinguish the two error channels. A **tool execution error** (`isError: true`) carries actionable text — "search backend timed out, retry", "unknown draft_id, create a new draft" — and should go back to the model as a `tool_result` with `is_error: true` so it can self-correct. A **protocol error** (a JSON-RPC error such as `-32602`) or a transport failure is less recoverable; the host should catch it, log it, and still return an `is_error` result rather than crash the loop. Stopping is the host's job: a `max_steps` budget, plus "do not retry" semantics for a declined confirmation.

### The notes server runs over stdio. Can it keep drafts in a global variable?
It can, but it shouldn't rely on it. The 2026-07-28 spec says a connection — including a stdio process — is not a session: the client may interleave unrelated requests, and clients SHOULD NOT tie the process lifetime to a conversation, so the process may be restarted between calls. State that spans requests MUST be referenced by an explicit identifier the client passes each time. Keep drafts in a store keyed by `<user>:<handle>`, make handles unguessable and expiring, and return a clear tool error for unknown handles.

### What stops a malicious client from editing `requestState` to skip the confirmation?
The server treats `requestState` as attacker-controlled. When it influences business logic it **MUST** be integrity-protected (HMAC or AEAD) and rejected if verification fails; the spec also recommends binding it to the authenticated principal, a short expiry and the originating request. The Python SDK seals it with AES-GCM and binds principal, audience and TTL by default. The capstone adds a content digest inside the state so an approval for one report can't publish a different one. If something must happen at most once, enforce that server-side too — sealed state alone does not guarantee single use.

### Two of your servers both expose a tool called `search`. How does the host cope?
Tool names are only unique within one server, and the spec says aggregating clients SHOULD implement a disambiguation strategy such as prefixing with a server identifier — and SHOULD NOT rely on `serverInfo.name`, which isn't guaranteed unique. Use the host's own connection key (`library__search`, `wiki__search`), keep names within the character set that both MCP and your model provider accept, and keep a routing table from namespaced name to (client, original name). Group tools by server in descriptions so the model can reason about which one to use.

## Glossary
- Host policy layer | 宿主策略层 | The part of the host that decides what the model may see and do: namespacing, allowlists, caching, truncation, audit and tracing.
- Tool allowlist | 工具白名单 | The explicit set of namespaced tools a workflow may call, enforced both in the catalog and at call time.
- Namespacing | 命名空间前缀 | Prefixing tool names with a host-chosen server key to avoid collisions across servers.
- State handle | 状态句柄 | An opaque, server-minted identifier (e.g. `draft_id`) passed as a tool argument to reference state across stateless requests.
- `InputRequiredResult` | 需要输入的结果（`InputRequiredResult`） | A result with `resultType: "input_required"` carrying `inputRequests` and/or `requestState`, asking the client to gather input and retry.
- `requestState` | 请求状态（`requestState`） | Opaque, server-owned state echoed by the client on an MRTR retry; untrusted, so it must be integrity-protected when it matters.
- Audit trail | 审计日志 | One structured record per tool call (tool, arguments, outcome, latency, trace id) for accountability and debugging.
- `traceparent` | 链路追踪头（`traceparent`） | The W3C Trace Context value, reserved in MCP `_meta`, that lets each call join a distributed trace.
- Scripted planner | 脚本化规划器（模拟 LLM） | A deterministic fake model with the real API's call shape, used to test agent systems offline.
- Prompt injection | 提示注入 | Instructions hidden in untrusted content (documents, tool results) that try to make the model take unintended actions.

```python
    uri: str
    title: str
    score: int
    snippet: str


class SearchPage(BaseModel):
    total: int
    hits: list[Hit]
    next_cursor: str | None = None


def _score(query: str, doc_id: str) -> int:
    words = set(re.findall(r"[a-z0-9]+", query.lower()))
    title, text = CORPUS[doc_id]
    tokens = re.findall(r"[a-z0-9]+", f"{title} {text}".lower())
    return sum(tokens.count(w) for w in words)


@library.tool()
def search_docs(query: str, cursor: str | None = None) -> SearchPage:
    """Search the research library by keywords. Returns at most 3 hits per page (uri, title, score and a
    160-character snippet). When `next_cursor` is not null, call again with the same query and that cursor
    to get the next page. Read a full document by passing its uri to host__read_resource."""

        SEARCH_FAULTS["remaining"] -= 1
        raise ToolError("search backend timed out — retry the same query")
    ranked = sorted((d for d in CORPUS if _score(query, d) > 0), key=lambda d: (-_score(query, d), d))
    try:
        start = int(base64.urlsafe_b64decode(cursor.encode()).decode()) if cursor else 0
    except ValueError:
        raise ToolError("invalid cursor — restart the search without one") from None
    page = ranked[start:start + PAGE_SIZE]
    nxt = start + PAGE_SIZE
    return SearchPage(
        total=len(ranked),
        hits=[Hit(uri=f"library://docs/{d}", title=CORPUS[d][0], score=_score(query, d),
                  snippet=CORPUS[d][1][:160] + "…") for d in page],
        next_cursor=base64.urlsafe_b64encode(str(nxt).encode()).decode() if nxt < len(ranked) else None)

        raise MCPError(types.INVALID_PARAMS, f"Resource not found: library://docs/{doc_id}")
    title, text = CORPUS[doc_id]
    return f"# {title}\n\n{text}"
```

### 2. The notes server over stdio: stateful work with explicit handles
MCP 2026-07-28 has **no protocol sessions**, and the spec says an open stdio process is *not* a session either. A drafting tool still needs state across calls, so the server follows the spec's "stateful tools" guidance: `create_draft` **mints an opaque, high-entropy handle** (`draft_id`), every other tool takes it as an argument, the lifetime is stated in the description, and an unknown handle is a tool execution error the model can recover from.

The state lives in a JSON file (a stand-in for a database), keyed `<user>:<handle>` — the user comes from the environment, which is how stdio servers get credentials. Server logs go to **stderr** (never stdout: that is the JSON-RPC channel), which we capture into a file.

```python
NOTES_SERVER = WORKDIR / "notes_server.py"
NOTES_SERVER.write_text(textwrap.dedent('''
    import json, logging, os, secrets, sys, time
    from pathlib import Path
    from pydantic import BaseModel
    from mcp.server import MCPServer
    from mcp.server.caching import CacheHint
    from mcp.server.mcpserver.exceptions import ToolError

    logging.basicConfig(stream=sys.stderr, level=logging.INFO, format="notes[%(process)d] %(message)s")
    log = logging.getLogger("notes")
    STORE = Path(os.environ["NOTES_STORE"])      # the "database"
    USER = os.environ.get("NOTES_USER", "local") # stdio: identity comes from the environment, not OAuth
    TTL_SECONDS = 24 * 3600

    mcp = MCPServer("notes", log_level="WARNING",
                    cache_hints={"tools/list": CacheHint(ttl_ms=300_000, scope="public")})

    def _load():
        return json.loads(STORE.read_text()) if STORE.exists() else {}

    def _draft(db, draft_id):
        d = db.get(f"{USER}:{draft_id}")          # bound to the user: a guessed handle of someone else misses
        if d is None or time.time() - d["updated"] > TTL_SECONDS:
            raise ToolError(f"unknown or expired draft_id {draft_id!r} - call create_draft to start a new draft")
        return d

    def _save(db, draft_id, d):
        d["updated"], d["version"] = time.time(), d["version"] + 1
        db[f"{USER}:{draft_id}"] = d
        STORE.write_text(json.dumps(db))

    def _markdown(d):
        return f"# {d['title']}\\n\\n" + "\\n\\n".join(f"## {h}\\n{t}" for h, t in d["sections"])

    class DraftRef(BaseModel):        # pydantic return types -> outputSchema + structuredContent
        draft_id: str
        title: str

    class DraftChange(BaseModel):
        draft_id: str
        sections: list[str]
        version: int

    class Draft(BaseModel):
        draft_id: str
        version: int
        markdown: str

    @mcp.tool()
    def create_draft(title: str) -> DraftRef:
        """Create an empty report draft and return its handle `draft_id`. Pass draft_id to every other notes
        tool. Drafts expire after 24 hours without changes."""
        db, draft_id = _load(), "drf_" + secrets.token_urlsafe(12)
        db[f"{USER}:{draft_id}"] = {"title": title, "sections": [], "updated": time.time(), "version": 0}
        _save(db, draft_id, db[f"{USER}:{draft_id}"])
        log.info("created %s pid=%s", draft_id, os.getpid())
        return DraftRef(draft_id=draft_id, title=title)

    @mcp.tool()
    def add_section(draft_id: str, heading: str, text: str) -> DraftChange:
        """Append a section (markdown text under a heading) to a draft."""
        db = _load(); d = _draft(db, draft_id)
        d["sections"].append([heading, text]); _save(db, draft_id, d)
        return DraftChange(draft_id=draft_id, sections=[h for h, _ in d["sections"]], version=d["version"])

    @mcp.tool()
    def revise_section(draft_id: str, heading: str, text: str) -> DraftChange:
        """Replace the text of an existing section of a draft."""
        db = _load(); d = _draft(db, draft_id)
        for s in d["sections"]:
            if s[0] == heading:
                s[1] = text; _save(db, draft_id, d)
                return DraftChange(draft_id=draft_id, sections=[h for h, _ in d["sections"]], version=d["version"])
        raise ToolError(f"no section {heading!r}; existing sections: {[h for h, _ in d['sections']]}")

    @mcp.tool()
    def get_draft(draft_id: str) -> Draft:
        """Return the full draft as markdown."""
        d = _draft(_load(), draft_id)
        return Draft(draft_id=draft_id, version=d["version"], markdown=_markdown(d))

    if __name__ == "__main__":
        mcp.run(transport="stdio")
'''))
```

### 3. The publisher server over Streamable HTTP: bearer token + human confirmation via MRTR
The third server is remote-shaped: a Streamable HTTP endpoint, protected as an OAuth **resource server**. The SDK's `token_verifier` + `AuthSettings` reject requests without a valid bearer token with `401` and a `WWW-Authenticate` header pointing at the Protected Resource Metadata (lesson 6.1). The "authorization server" here is a dict of demo tokens.

`publish` is irreversible, so it asks the human. In 2026-07-28 a server may not send its own `elicitation/create` request; it **returns** an `InputRequiredResult` (`resultType: "input_required"`) carrying `inputRequests` and an opaque `requestState`, and the client retries with `inputResponses` (lesson 5.3). The tool also:

- refuses with `-32021` if the client did not declare the `elicitation` capability (a server MUST NOT send input requests the client can't handle);
- binds the confirmation to a digest of the content, so a retry with *different* content can't reuse the approval;
- relies on the SDK to **seal** `requestState` (AES-GCM, bound to the token's principal and a TTL) — the client sees only an opaque blob.

```python
PUB_PORT = free_port()

class DemoTokenVerifier:

        user = DEMO_TOKENS.get(token)
        if user is None:
            return None
        return AccessToken(token=token, client_id="research-host", subject=user,
                           scopes=["reports:write"], resource=PUB_URL)   # audience = this server

    auth=AuthSettings(issuer_url="https://auth.example.com", resource_server_url=PUB_URL,
                      validate_token_resource=True, required_scopes=["reports:write"]),
    cache_hints={"tools/list": CacheHint(ttl_ms=300_000, scope="public")})

                  "properties": {"approve": {"type": "boolean", "title": "Publish this report?"}},
                  "required": ["approve"]}


@publisher.tool()
async def publish(title: str, body: str, ctx: Context) -> types.CallToolResult | types.InputRequiredResult:
    """Publish a finished markdown report to the team wiki. Irreversible: the user is asked to confirm."""
    meta = ctx.request_context.meta or {}
    PUBLISHER_SAW.append({"user": get_access_token().subject, "traceparent": meta.get("traceparent"),
                          "round": "retry" if ctx.input_responses else "first"})
    caps = ctx.client_capabilities
    if caps is None or caps.elicitation is None:
        raise MCPError(types.MISSING_REQUIRED_CLIENT_CAPABILITY, "publish needs user confirmation (elicitation)",
                       {"requiredCapabilities": {"elicitation": {}}})
    digest = hashlib.sha256(f"{title}\n{body}".encode()).hexdigest()[:16]
    answer = (ctx.input_responses or {}).get("confirm")
    if answer is None:                                   # round 1: ask the human, keep no server-side state
        return types.InputRequiredResult(
            input_requests={"confirm": types.ElicitRequest(params=types.ElicitRequestFormParams(
                message=f"Publish the report '{title}' ({len(body)} chars) to the team wiki?",
                requested_schema=CONFIRM_SCHEMA))},
            request_state=json.dumps({"digest": digest}))
    if json.loads(ctx.request_state or "{}").get("digest") != digest:
        raise ToolError("the report changed after confirmation - call publish again")
    if answer.action != "accept" or not (answer.content or {}).get("approve"):
        return types.CallToolResult(is_error=True, content=[types.TextContent(
            type="text", text=f"The user declined publication (action={answer.action}). Do not retry.")])
    report_id = "rpt_" + secrets.token_hex(4)
    REPORTS[report_id] = {"title": title, "body": body, "owner": get_access_token().subject}
    url = f"https://wiki.example.com/reports/{report_id}"
    return types.CallToolResult(content=[types.TextContent(type="text", text=f"Published {report_id} at {url}")],
                                structured_content={"report_id": report_id, "url": url})


@publisher.tool()
def unpublish(report_id: str) -> str:
    """Delete a published report. Destructive."""
    REPORTS.pop(report_id, None)
    return f"deleted {report_id}"


pub_http = uvicorn.Server(uvicorn.Config(publisher.streamable_http_app(), host="127.0.0.1", port=PUB_PORT,
                                         log_level="warning"))
threading.Thread(target=pub_http.run, daemon=True).start()
```

### 6. The host: connect, namespace, cache, allowlist, route, audit
The **host** is where policy lives. Servers are untrusted plug-ins; the host decides what the model may see and do:

| Responsibility | How this host does it |
| --- | --- |
| Connections | one `Client` per server, opened together in an `AsyncExitStack` |
| Namespacing | `server__tool` names (the spec says aggregators SHOULD disambiguate; `serverInfo.name` is not unique) |
| Caching | memoises the merged catalog until the smallest `ttlMs` expires |
| Least privilege | an **allowlist** filters the catalog *and* is re-checked on every call |
| Resources in the loop | a host tool `host__read_resource` that only reads URIs of connected servers, truncated |
| Observability | an audit record per call + a W3C `traceparent` in `_meta` on every request |
| Context hygiene | tool output truncated before it reaches the model |

```python
SEP = "__"
MAX_RESULT_CHARS = 1500


class Host:
    def __init__(self, factories: dict, allowlist: set[str]):
        self.factories, self.allowlist = factories, allowlist
        self.clients: dict[str, Client] = {}
        self.audit: list[dict] = []
        self.catalog_fetches = 0
        self._catalog, self._fresh_until = None, 0.0
        self.trace_id = secrets.token_hex(16)

    async def __aenter__(self):
        self._stack = AsyncExitStack()
        for name, factory in self.factories.items():
            self.clients[name] = await self._stack.enter_async_context(factory())
        return self

    async def __aexit__(self, *exc):
        await self._stack.aclose()

    # ---- discovery ------------------------------------------------------------------------------
    async def tools(self) -> list[dict]:
        """Anthropic-shaped tool list: namespaced, allowlisted, cached per ttlMs."""
        if self._catalog is not None and time.monotonic() < self._fresh_until:
            return self._catalog
        self.catalog_fetches += 1
        catalog, ttl = [], 3_600_000
        for server, client in self.clients.items():
            listing = await client.list_tools()
            ttl = min(ttl, listing.ttl_ms)
            for t in listing.tools:
                name = f"{server}{SEP}{t.name}"
                if name in self.allowlist:
                    catalog.append({"name": name, "description": f"[{server}] {t.description}",
                                    "input_schema": t.input_schema})
        catalog.append({"name": "host__read_resource",
                        "description": "Read a document by uri (e.g. library://docs/<id>) from a connected server. "
                                       "Long documents are truncated.",
                        "input_schema": {"type": "object", "properties": {"uri": {"type": "string"}},
                                         "required": ["uri"]}})
        self._catalog, self._fresh_until = catalog, time.monotonic() + ttl / 1000
        return catalog

    # ---- execution -----------------------------------------------------------------------------
    async def call(self, name: str, args: dict, step: int) -> tuple[str, bool]:
        """Route one model tool call. Returns (text for the model, is_error). Never raises."""
        traceparent = f"00-{self.trace_id}-{secrets.token_hex(8)}-01"
        record = {"step": step, "tool": name, "args": json.dumps(args)[:80], "traceparent": traceparent}
        started = time.perf_counter()
        try:
            text, is_error = await self._dispatch(name, args, traceparent)
            record["outcome"] = "tool_error" if is_error else "ok"
        except PermissionError as exc:
            text, is_error, record["outcome"] = f"Denied by host policy: {exc}", True, "denied"
        except MCPError as exc:                       # protocol error from a server
            text, is_error, record["outcome"] = f"Protocol error {exc.code}: {exc.message}", True, "protocol_error"
        except Exception as exc:                      # transport failure, timeout, ...
            text, is_error, record["outcome"] = f"Host error: {type(exc).__name__}: {exc}", True, "host_error"
        record["ms"] = round((time.perf_counter() - started) * 1000, 1)
        self.audit.append(record)
        if len(text) > MAX_RESULT_CHARS:
            text = text[:MAX_RESULT_CHARS] + f"\n[truncated {len(text) - MAX_RESULT_CHARS} chars]"
        return text, is_error

    async def _dispatch(self, name: str, args: dict, traceparent: str) -> tuple[str, bool]:
        meta = {"traceparent": traceparent}
        if name == "host__read_resource":
            uri = str(args.get("uri", ""))
            server = uri.split("://", 1)[0]
            if server not in self.clients:
                raise PermissionError(f"no connected server owns {uri!r}")
            result = await self.clients[server].read_resource(uri)
            return "\n".join(getattr(c, "text", "") or "" for c in result.contents), False
        if name not in self.allowlist:
            raise PermissionError(f"tool {name!r} is not on this workflow's allowlist")
        server, _, tool = name.partition(SEP)
        result = await self.clients[server].call_tool(tool, args, meta=meta)
        if result.structured_content is not None:
            text = json.dumps(result.structured_content, ensure_ascii=False)
        else:
            text = "\n".join(c.text for c in result.content if isinstance(c, types.TextContent))
        return text, result.is_error

    def print_audit(self):
        for r in self.audit:
            print(f"  step {r['step']:>2}  {r['outcome']:<14} {r['ms']:>7.1f} ms  {r['tool']:<26} {r['args'][:46]}")


ALLOWLIST = {"library__search_docs", "notes__create_draft", "notes__add_section", "notes__revise_section",
             "notes__get_draft", "publisher__publish"}          # note: publisher__unpublish is NOT allowed


def make_host(human: ScriptedHuman, allowlist=ALLOWLIST) -> Host:
    return Host({"library": lambda: Client(library),
                 "notes": notes_client,
                 "publisher": lambda: publisher_client("tok-alice-publisher", human)}, allowlist)


async with make_host(ScriptedHuman()) as host:
    tools = await host.tools()
    tools_again = await host.tools()
    print("model sees", len(tools), "tools:", [t["name"] for t in tools])
    print("catalog fetched", host.catalog_fetches, "time(s) for 2 requests (cached per ttlMs)")
    print(await host.call("publisher__unpublish", {"report_id": "x"}, step=0))
    print(await host.call("host__read_resource", {"uri": "file:///etc/passwd"}, step=0))
    host.print_audit()
```

### 7. The planner and the agent loop
The loop is the standard Claude tool-use loop: call the model with the tools; while `stop_reason == "tool_use"`, run **every** `tool_use` block, append the assistant turn and then **one** user turn holding all `tool_result` blocks (with `is_error`), and call the model again — capped by `max_steps`.

To run offline, `ScriptedPlanner` is a deterministic fake LLM with the *same* `create(model=, max_tokens=, tools=, messages=)` signature and Anthropic-shaped `tool_use` blocks. It is not a hard-coded script of calls: like a model, it reads the tool results in `messages` (hits, URIs, `draft_id`, errors) to choose the next step. The `gullible` flag makes it obey instructions found inside documents — a model successfully prompt-injected.

```python
MODEL = "claude-opus-5-5"
TASK = ("Research how MCP servers scale horizontally, write a short cited report in my notes, "
        "and publish it to the team wiki.")


@dataclass
class Block:                       # mimics anthropic's TextBlock / ToolUseBlock
    type: str
    text: str | None = None
    id: str | None = None
    name: str | None = None
    input: dict | None = None


@dataclass
class FakeResponse:
    content: list
    stop_reason: str


def last_turn(messages):
    """(tool_use, result) pairs of the most recent assistant turn."""
    if len(messages) < 3:
        return []
    results = {r["tool_use_id"]: r for r in messages[-1]["content"]}
    return [(b, results[b.id]) for b in messages[-2]["content"] if b.type == "tool_use"]


class ScriptedPlanner:
    """A deterministic stand-in for Claude. Same call shape as client.messages.create."""

    def __init__(self, gullible: bool = False):
        self.gullible, self.n, self.hits, self.sources, self.draft_id = gullible, 0, [], [], None
        self.searches = 0

    def _use(self, name, **args):
        self.n += 1
        return Block(type="tool_use", id=f"toolu_{self.n:02d}", name=name, input=args)

    def create(self, *, model, max_tokens, tools, messages):
        blocks = self.plan(messages)
        if blocks and blocks[0].type == "tool_use":
            return FakeResponse([Block(type="text", text="(planning)")] + blocks, "tool_use")
        return FakeResponse(blocks, "end_turn")

    def plan(self, messages):
        turn = last_turn(messages)
        if not turn:
            self.searches += 1
            return [self._use("library__search_docs", query="stateless scaling load balancer")]
        call, result = turn[-1]
        text, failed = result["content"], result["is_error"]
        if call.name == "library__search_docs":
            if failed:                                       # transient failure: retry the same call once
                return [self._use(call.name, **call.input)]
            page = json.loads(text)
            self.hits += page["hits"]
            if page["next_cursor"] and self.searches < 2:
                self.searches += 1
                return [self._use(call.name, query=call.input["query"], cursor=page["next_cursor"])]
            top = sorted(self.hits, key=lambda h: -h["score"])[:2]
            return [self._use("host__read_resource", uri=h["uri"]) for h in top]   # parallel tool calls
        if call.name == "host__read_resource":
            self.sources = [(c.input["uri"], r["content"]) for c, r in turn if not r["is_error"]]
            injected = re.search(r"call (\w+) with report_id='([^']*)'", " ".join(t for _, t in self.sources))
            if self.gullible and injected:
                return [self._use(injected.group(1), report_id=injected.group(2))]
            return [self._use("notes__create_draft", title="How MCP servers scale horizontally")]
        if call.name == "publisher__unpublish":              # the injected detour failed; back on task
            return [self._use("notes__create_draft", title="How MCP servers scale horizontally")]
        if call.name == "notes__create_draft":
            self.draft_id = json.loads(text)["draft_id"]
            findings = "\n".join(f"- {body.split(chr(10))[-1].split('. ')[0]}. [{i}]"
                                 for i, (_, body) in enumerate(self.sources, 1))
            refs = "\n".join(f"[{i}] {uri}" for i, (uri, _) in enumerate(self.sources, 1))
            return [self._use("notes__add_section", draft_id=self.draft_id, heading="Findings", text=findings),
                    self._use("notes__add_section", draft_id=self.draft_id, heading="Sources", text=refs)]
        if call.name == "notes__add_section":
            summary = ("MCP 2026-07-28 requests are self-contained, so servers scale behind an ordinary "
                       "round-robin load balancer; keep cross-call state behind explicit handles. [1][2]")
            return [self._use("notes__revise_section", draft_id=self.draft_id, heading="Findings",
                              text=summary + "\n" + turn[0][0].input["text"])]
        if call.name == "notes__revise_section":
            return [self._use("notes__get_draft", draft_id=self.draft_id)]
        if call.name == "notes__get_draft":
            draft = json.loads(text)
            return [self._use("publisher__publish", title="How MCP servers scale horizontally",
                              body=draft["markdown"])]
        if call.name == "publisher__publish":
            if failed:
                return [Block(type="text", text=f"I drafted the report ({self.draft_id}) but did not publish it: {text}")]
            return [Block(type="text", text=f"Done. Published at {json.loads(text)['url']} (draft {self.draft_id}).")]
        return [Block(type="text", text=f"Stopping: unexpected state after {call.name}.")]


async def run_agent(llm, host: Host, task: str, max_steps: int = 12, verbose: bool = True) -> dict:
    """The manual Claude tool-use loop, with the host enforcing policy on every call."""
    tools = await host.tools()
    messages = [{"role": "user", "content": task}]
    response = llm.create(model=MODEL, max_tokens=16000, tools=tools, messages=messages)
    steps = 0
    while response.stop_reason == "tool_use":
        steps += 1
        if steps > max_steps:
            return {"final": f"stopped: exceeded max_steps={max_steps}", "steps": steps - 1, "messages": messages}
        messages.append({"role": "assistant", "content": response.content})
        results = []
        for block in response.content:
            if block.type == "tool_use":
                text, is_error = await host.call(block.name, block.input, step=steps)
                if verbose:
                    flag = "ERR" if is_error else "ok "
                    print(f"step {steps:>2} {flag} {block.name}({json.dumps(block.input)[:60]}) -> {text[:70]!r}")
                results.append({"type": "tool_result", "tool_use_id": block.id, "content": text,
                                "is_error": is_error})
        messages.append({"role": "user", "content": results})
        tools = await host.tools()                       # served from the host cache while fresh
        response = llm.create(model=MODEL, max_tokens=16000, tools=tools, messages=messages)
    final = "".join(b.text for b in response.content if b.type == "text")
    return {"final": final, "steps": steps, "messages": messages}
```

### 9. Break it: a flaky tool, a prompt injection, a "no"
Three failures a production workflow must survive:

1. **Transient tool failure** — the search backend times out once; the error comes back as `isError: true`, and the planner retries.
2. **Prompt injection** — the gullible planner obeys the "SYSTEM NOTE" hidden in a document and tries `publisher__unpublish`. The **host allowlist** blocks it before any server sees it: the defence is in code, not in the model's good behaviour.
3. **Human declines** — `publish` returns a tool error, the loop ends cleanly, nothing is published.

```python
REPORTS.clear()
SEARCH_FAULTS["remaining"] = 1
naysayer = ScriptedHuman(approve=False)
async with make_host(naysayer) as chaos_host:
    chaos = await run_agent(ScriptedPlanner(gullible=True), chaos_host, TASK)

print("\nFINAL:", chaos["final"])
print("published reports:", REPORTS)
outcomes = [r["outcome"] for r in chaos_host.audit]
print("outcomes:", {o: outcomes.count(o) for o in sorted(set(outcomes))})
chaos_host.print_audit()
```

And the loop's own guard rail — `max_steps` — stops a planner that never converges:

```python
class LoopingPlanner(ScriptedPlanner):
    def plan(self, messages):                       # keeps searching forever
        return [self._use("library__search_docs", query="mcp")]


async with make_host(ScriptedHuman()) as host:
    stuck = await run_agent(LoopingPlanner(), host, TASK, max_steps=4, verbose=False)
print(stuck["final"], "| calls made:", len(host.audit))
```
